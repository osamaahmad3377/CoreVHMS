# Feature Matrix — NextCore VCMS

Status key: **Done** = meets the Definition of Done (UI + API + DB + validation + permissions + audit + states + tests) · **Partial** = usable but missing listed items · **Planned** = not started (hidden from navigation).

_Last updated: 2026-10-16 (end of Milestone 10; Milestone 9 deferred)._
